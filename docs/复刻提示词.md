# 复刻提示词

给想用 AI 重做这个项目的人。

先说清楚一件事：**一个提示词做不出来。** 这个 `index.html` 是 2048 行手调代码，
里面绝大多数数字（Sobel 阈值、色调曲线指数、点云预算、转场振幅）不是推导出来的，
是「截图 → 看 → 改 → 再截图」调出来的。你一次性让它写，只会得到一坨能跑但读不出机器的噪点。

所以下面给的是**一套分轮提示词 + 一张参数表 + 一张踩坑表**。每一轮都有验收标准，
过不了就别往下走 —— 第 2 轮机器认不出来，后面 14 台机型全白做。

预期投入：会用 AI 的人 1–2 天，不会的人一周。

## 第 0 轮：主提示词（每轮开头都粘这段）

```text
你是一名「生成艺术 + 前端工程」方向的独立开发者。我们要做一个单页项目，最终产出一部短片。

## 成品是什么

一部 4 分 18 秒的中文科普短片《个人电脑发展史 —— 终端 ASCII 3D》，
外加一个能在浏览器里交互播放它的单文件网页。

全片是一个**虚构的 1975 年终端**在逐台自检 14 代个人电脑：
1975 Altair 8800 → 1977 Apple ][ → 1981 IBM PC 5150 → 1982 Commodore 64 →
1986 Compaq Deskpro 386 → 1995 Windows 95 PC → 1998 iMac G3 →
2003 ThinkPad T40 → 2007 Eee PC → 2010 iPad → 2012 树莓派 →
2016 游戏本 → 2020 Mac mini M1 → 2026 AI PC。

每一镜有四层信息：
1. 左上：POST 自检面板（机型名 + CPU/内存/存储/价格，逐行打字，行尾 OK）
2. 中央：这台机器的 3D 模型，实时渲染成**字符画**（点云采样 → 逐字符映射）
3. 下方：一条 1975–2026 的时间轴，当前代高亮
4. 右下：机型铭牌（英文型号大字 + 中文名）

## 视觉设定（这是项目的灵魂，不要改）

- 装饰画布固定 **1600×960**，CSS `transform: scale()` 自适应窗口
- 每一镜只用**一种磷光色**主调，整片在琥珀 / 绿 / 白 / 青 / 品红之间轮换
- 叠加 CRT 质感：扫描线、荫罩、暗角、玻璃反光
- 字体 `"Cascadia Mono","Consolas","SF Mono","Menlo","Microsoft YaHei",monospace`
- 中文按 2 个字符格宽算（`codePointAt(0) > 0x2e80`）

## 技术硬约束

- **单文件 `index.html`，零依赖、零构建**：双击就能离线打开，不许引 three.js、不许引 CDN、不许 npm
- 3D 必须是**真的 3D**：真实几何 → 真实投影 → 再把投影结果逐字符映射到 2D canvas。
  不许手写假的 ASCII 图案，不许用图片
- 渲染走**纯 JS 软件投影 + z-buffer**，用 Canvas 2D 画字符。不要用 WebGL ——
  点云渲染不需要光栅化三角形，自己算投影才能精确控制每个点落到哪一格
- 动画必须是**确定性**的：同一时间点永远出同一帧。全项目禁用 `Math.random()`，
  随机数一律用固定种子的线性同余（`Math.imul`）
- 交互：SPACE 暂停 / ←→ 切镜 / R 重播 / C 单色↔真彩 / M 音效 / F 全屏

## 工作方式（重要）

我们分轮做，每轮只做一件事，做完我用无头浏览器截图验收，过了再做下一轮。
你不要一次把全部写完。每一轮结束请停下来等我确认。

如果某一轮里我给的验收标准没达到，你要自己先看截图诊断，说出你判断的原因，
再改。不要盲目改数字。
```

## 第 1 轮：骨架

```text
这一轮只做骨架，不做 3D。

1. 创建 index.html，画布 1600×960（逻辑尺寸），`#stage` 用 transform scale 自适应。
2. 搭四层 DOM：`#screen`（字符画主画布）、`#bloom`（辉光）、CRT 层
   （`#scan` 扫描线 / `#mask` 荫罩 / `#vig` 暗角 / `#glass` 玻璃反光 / `#flick` 闪烁）。
3. 字符网格：160 列 × 48 行，每格 10×20px。写一个 `drawStr(col,row,text,style)` 工具，
   中文自动占 2 格。
4. **在 <head> 里加一个自检层**：监听 window.onerror 和 unhandledrejection，
   把错误信息写进页面最底部一条固定的红色横条 `#jserr`。
   —— 这条很重要：无头截图时 JS 报错会直接显示在画面里，否则你只能看到一片黑。
5. 加调试参数：`?stage=N&freeze=T` 把第 N 镜快进到第 T 秒并暂停；
   `?still=1` 定格后只画几帧就停掉 rAF 循环（让无头截图立刻完成）。
6. 画一帧静态画面验证：左上角一个 POST 面板框（用 ─ │ ┌ ┐ └ ┘ 画），
   下方一条 1975–2026 的时间轴，右下角一个铭牌。用磷光色。

验收：我用 `?stage=0&freeze=1` 截图，能看清一个终端界面，底部没有红色报错条。
```

## 第 2 轮：点云管线（**最关键，别跳**）

```text
这一轮做「盒子 → 点云 → 字符」的完整管线。**只做一台机器**：Altair 8800
（一个扁箱子，前面板一排拨动开关和一排 LED）。做对了再谈其他机器。

不要用 WebGL，不要用 three.js。整条管线是纯 JS + Canvas 2D：

1. **建模层**：机器 = 一串**有朝向的盒子**。每个盒子记录 3 个正交轴向量、
   中心位移、三轴半尺寸、颜色、强调色 ID。拼一个 Altair 大概 20～80 个盒子就够。
2. **采样层**：把每个盒子的**六个面**按网格采成点。
   - 朝 +Z（朝向镜头）的那一面**加密 3.2 倍**——面板上的拨动开关、软驱、接口
     全靠采样密度分辨，不靠几何
   - 每个面单独存成一段 seg（起止下标、面法线、颜色、反照率）
   - 反照率必须单独存：`alb = 0.299r + 0.587g + 0.114b`。
     只看法线的话，同一个朝向上的近黑凹槽和白色开关会算出**一模一样的亮度**
3. **收敛层**：采完数一下点数，按 `sqrt(目标/实际)` 缩放间距重采，迭代到 78000 点。
4. **投影层**：自己算视图矩阵和透视投影。逐 seg 做背面剔除（法线 nz > 0.02 就丢），
   再把点投到屏幕，落到 3×3 超采样的缓冲里，z-buffer 只留最近的点。
5. **归约层**：3×3 → 120×45 字符格，每格统计覆盖率、平均亮度、平均法线。
   再乘一个深度提示 `k = 0.16 / (z1 - z0)`，越远越暗。
6. **字符映射**（全项目最影响观感的一段，参数照抄下表）：
   - 用 3×3 Sobel 求亮度梯度，得到轮廓
   - 覆盖率不足的格子是抗锯齿边，按比例柔化
   - 「覆盖率满 → 空」的那一圈是剪影，单独加一笔描边
   - 最终权重 `v = base*0.68 + edge*0.50 + sil*0.34`，再乘 `(0.35+0.65*soft)`
   - 字符梯度用 `" .:-=+*#%@"` 十级

验收：截图能一眼认出「一台有前面板开关的扁平机箱」。如果是一团噪点，先看踩坑表 §2。
```

## 第 3 轮：十四台机器

```text
按第 2 轮的管线，把剩下 13 台机器做出来。每台单独一个 build 函数，追加到 STAGES 数组。

每台机器要写的是：型号名、年份、中文名、磷光色相、强调色、方位角、俯仰角、自转系数、
留白比例、build 函数、POST 面板的 6–8 行内容、两行解说文案。

建模要点：
- 只用 box 拼，不要曲面 —— 在 120×45 的字符网格下曲面等于噪点。
- **保特征**：每台机器至少有一个「一眼认出是它」的部件，并且把它放大画。
  例：Mac mini 背面接口排（真实比例下只有三四格高，必须夸张一倍）；
  ThinkPad 的小红点；Eee PC 的小屏幕配大键盘；iMac G3 的果冻外壳。
- 相机方位角每台独立调，不要共用一个。键盘朝镜头时是笔记本，屏幕朝镜头时是显示器，
  这一点决定这台机器读不读得出来。
- 归一化：算包围盒中心，把模型平移到原点，同时算出旋转安全半径 R 和高度 Hh，
  后面取景都用它。

验收：我给 14 张截图，每张都能认出是那台机器。
```

## 第 5 轮：镜头语言

```text
现在 14 个镜头看起来全一样，因为共用同一台摄影机。补四件事：

1. **镜头语法**：给每台机器加一个 shot 字段
   - `hero`：基准，缓慢 ±26° 摆动
   - `dolly`：单向前推，距离从 1.26 倍收到 0.76 倍
   - `crane`：从 32° 俯角降下来，前 62% 的时间里归位
   - `orbit`：横向摆动幅度 ×1.85
   分配：Altair/AI PC 用 dolly，C64/游戏本用 orbit，iMac/Mac mini 用 crane，其余 hero。
2. **世代转场**（1.15 秒）：旧机器的点云被**竖向字符流**冲走，新机器的点云从同一片字符里
   长出来。两朵云共用一张深度缓冲，遮挡要真。
   —— 注意不要做成「径向爆散」，那样会散成一整屏均匀噪点，读不出在变形。
   改成竖向：x 加随机抖动，y 主要向下坠，z 轻微散开。
3. **插入镜「剖面」**：只给 IBM PC 那一镜，第 7.2–10.4 秒点云按径向拆开再合拢，
   振幅 1.15R，抖动 0.28。（振幅再大就散成噪点，再小就看不出来）
4. 片头 0.8 秒 **CRT 上电**：从一条亮线开始，上下黑幕用 (1-(1-p)^3) 张开，前 22% 白闪。

验收：截转场中间三帧，能看出「旧机器在解体、新机器在成形」，不是一片乱码。
```

## 第 6 轮：出片

```text
现在要录成 mp4。不要录屏 —— 录屏帧率被浏览器绑死，窗口一动就掉帧。

1. 页面加 `?render=1` 模式：不跑 rAF，由外部按 1/fps 的节拍调 `__renderFrame(fps)`，
   页面内部用 1/60 的细步长把时间线确定性推进。暴露 `__TOTAL_SEC()`、`__TOTAL_FRAMES(fps)`。
2. 写 `tools/render-video.mjs`：用 CDP 连无头 Chrome，逐帧 `Page.captureScreenshot` 存 jpg，
   最后交给 ffmpeg 编码。
3. 辉光优化：CSS 的整屏 `filter: blur(7px)` + `mix-blend-mode: screen` 在无头软件合成下
   一帧要 900ms。改成先在 400×240 的小图上模糊再放大混合，等效半径 8.8px，一帧降到几毫秒。
4. 键击声：录片时不真发声，只把 `[时间, 力度, 抖动, 速率]` 记进数组，
   最后用 OfflineAudioContext 一次性合成整条音轨。
   —— 这一步在无头 Chrome 里**经常卡死**（几千次键击一次性离线合成，CPU 在跑但就是不返回）。
   所以出片脚本要给一个 `--audio=0` 开关跳过它，键击轨从上版成片里抽出来复用，
   见踩坑表 §15。

验收：能出一条 1600×960 / 15fps 的 mp4，`ffmpeg -f null -` 解码无错。
```

## 第 7 轮：旁白与字幕

```text
给片子配中文旁白并烧进画面。

1. 写 15 条文案（14 代各一条 + 1 条收尾），存 tools/narration.json。
   语气：第三人称纪录片腔，每条约 60–80 字，讲「这台机器为什么重要」而不是参数表。
2. 用 edge-tts 合成，声音 zh-CN-YunyangNeural，-8% 语速。
3. 从页面导出每镜的 start/dur（tools/timing.json），按 start + lead 排旁白入点。
4. 闪避混音：旁白做 sidechain，压住键击底噪（threshold .05 / ratio 6 / attack 25 / release 450）。
5. 响度归一化 loudnorm I=-16 TP=-1.5 LRA=11，**后面必须补 aresample=44100**。
6. 把 SRT 转成带样式的 ASS，用 libass 烧进画面。

三条硬要求：
- 字幕带在**时间轴上方**那条空带（MarginV=148），不能在画面最底 —— 最下沿全是自己的 HUD
- 一条长旁白要按标点切成 ≤30 字的单行，否则 libass 自动折两行，第二行会压到时间轴上
- `——` 当整体消费，但**不做断句点**（否则字幕以破折号收尾，像没说完）

验收：成片带声音带字幕，字幕任何一句都不压到时间轴和铭牌。
```

### 着色

| 项 | 值 |
|---|---|
| 环境光 `AMBIENT` | 0.11 |
| 主光 `KEY_GAIN` | 0.92 |
| 边缘光 `RIM_GAIN` | 0.22 |
| 边缘光指数 `RIM_POW` | 3.0 |
| 主光方向 `K` | (-0.28, 0.34, -0.90) |
| 背面剔除 | `nvz > 0.02` 就丢 |

### 字符映射

```
base = clamp((lum - 0.035) / 0.62) ^ 0.82
edge = max(0, hypot(ex, ey) - 1.20) * 0.54        // Sobel，阈值 1.20 抑制低分辨率碎边
sil  = (覆盖率 >= 2 且有邻居覆盖率为 0) ? 1 : 0     // 剪影
soft = min(1, 覆盖率 / (9 * 0.55))                  // 3×3 全满 = 1
v    = (base * 0.68 + edge * 0.50 + sil * 0.34) * (0.35 + 0.65 * soft)
if (v < 0.055) 这一格不画
字符级 = round(v ^ 0.75 * 9)
```

Sobel 求梯度时，**空白邻居用自身亮度填充**，不要让外轮廓产生假边 ——
外轮廓交给 `sil` 那一项，那才是点云白送的东西。

### 时间

| 项 | 值 |
|---|---|
| 3D 打印扫描线 | 1.9 秒自上而下 |
| POST 打字 | 82 字符/秒，换行停 0.13 秒 |
| 解说打字 | 34 字符/秒 |
| 每镜时长 | `1.9 + 0.55 + 打字时长 + 0.35 + 解说时长 + 2.1` |
| 转场 | 1.15 秒 |
| 成片 | 15 fps，258.47 秒，3742 帧 |

## 踩坑表（症状 → 原因 → 做法）

按「你要是踩了会浪费多少时间」排序。

### §1 无头截图一片黑，不知道哪错了

**原因**：JS 异常了，但页面上什么都不显示。
**做法**：`<head>` 里就装 `window.onerror` + `unhandledrejection` 钩子，把错误写进
页面底部的红色横条。**这是整个项目性价比最高的一段代码。**
它至少帮你定位了 5 次 bug，包括一次 `SyntaxError` 精确到行号。

### §2 机器渲染出来是一团噪点，认不出是什么

**原因**：3D 网格太粗（早期用的是 160×36，Altair 的 32 个拨动开关全挤成一格）。
**做法**：3D 区用**独立的、比文本更细的字符格** 8×16px，网格 120×45。
另外三件事同时做：
- Sobel 加阈值 `1.20` 抑制低分辨率碎边：`max(0, hypot(ex,ey) - 1.20) * 0.54`
- 加边缘光 `rim = pow(1 - |nvz|, 3.0)`，`k += 0.30 * rim`，让轮廓自然发亮
- 把色调曲线换到参数表里那一组（`base` 用 0.035 / 0.62 / 0.82，
  而不是直觉上的 0 / 1 / 1）—— 压低暗部、拉开中间调，字符梯度才有层次

### §3 整片泛灰，看起来像卡在某一帧

**原因**：`advance(dt)` 第一行是 `if (S.ended || !S.playing) return;`，
录片时推进完把 `S.playing` 置回了 false，于是**只有第一帧真的推进**。
**做法**：录片模式下全程 `S.playing = true`。

### §4 出片一帧要 900 毫秒

**原因**：`#bloom` 是整屏 1600×960 的 `filter: blur(7px)` + `mix-blend-mode: screen`，
软件合成下贵得离谱，占 70% 耗时。
**做法**：录片模式下隐藏 `#bloom`，改成在 canvas 里对 400×240 的小图模糊再放大混合。

### §5 录出来的视频只有 1576×805

**原因**：`--window-size=1600,960` 在 headless=new 下给的是**外框**尺寸。
**做法**：补一次 `Emulation.setDeviceMetricsOverride`。

### §6 PowerShell 脚本里的中文全乱码

**原因**：Windows PowerShell 5.1 读**无 BOM 的 .ps1** 会按 ANSI 解码。
**做法**：所有 `.ps1` 保持**纯 ASCII**。中文路径用 `[uri]::EscapeUriString()` 转义，
中文标点用码点构造：`[char]0xFF0C` 是 `，`，`[char]0x3002` 是 `。`。

### §7 用字符串替换改脚本，静默没替换成功

**原因**：同 §6 —— 含中文的 here-string 被 ANSI 解码后，`$t.Replace($old,$new)` 锚点匹配不到，
而且**不报错**。
**做法**：改脚本时锚点一律用 ASCII 片段，或者按行号数组赋值。

### §8 ffmpeg 报 `Unable to parse "st" option value "=1"`

**原因**：PowerShell 双引号里 `"st=$endHold:d=$endFade"` 会被解析成 `${endHold:d}` ——
冒号在 PowerShell 里是作用域限定符。
**做法**：**变量后面紧跟冒号时必须写 `${endHold}`。**

### §9 ffmpeg 打不开文件，路径显示成一堆 `?`

**原因**：ffmpeg 的部分命令行（尤其是 concat demuxer）处理不了含中文的绝对路径。
**做法**：`Push-Location` 进目录，用裸文件名。

### §10 loudnorm 之后音频采样率变成 96k

**原因**：`loudnorm` 内部跑 192k。
**做法**：归一化之后补 `aresample=44100`。

### §11 内存数字对不上

**原因**：用了 10³/10⁶/10⁹ 换单位，M1 Mac mini 的 8 GB 会显示成 9 GB。
**做法**：**计算机史里内存一律用二进制单位**（1024/1048576/1073741824）。
8 GB 就是 8 GB，640 KB 就是 640 KB。

### §12 转场看起来像一屏雪花

**原因**：径向爆散 + 振幅太大，机器在两三帧内就散成均匀噪点。
**做法**：改成**竖向字符流**，振幅收到 1.9R，并且让两朵云的时间窗错开
（旧的 0–52%，新的 40–100%），中间留一段「旧机器掉了、新机器还没长出来」的空拍。

### §13 剖面镜读不出「拆开」

**原因**：振幅 2.0R + 抖动 1.0，直接散成一团。
**做法**：径向为主、抖动为辅 —— 振幅 1.15R，抖动 0.28，抖动权重压到 0.35 以下。

### §14 转场时机器缺了一半

**原因**：`draw()` 里的「打印扫描线」还在生效，把爆散出去的点裁掉了。
**做法**：转场期间 `reveal = 1`、`dens = 1`，绕过扫描线。

### §15 `OfflineAudioContext` 合成音轨卡死半小时

**原因**：几千次键击一次性离线合成，无头 Chrome 里可能永远不返回（CPU 在跑，就是没结果）。
**做法**：出片时用 `--audio=0` 跳过，键击轨从上版成片里抽出来复用
（键击时间点完全由 POST 打字进度决定，文案不改就一模一样）。

### §16 插一个函数进去，结果吞掉了下一行的函数签名

**原因**：用 `function drawHeader(s) {` 这种短锚点做替换，而它在别处也出现过。
**做法**：替换前先确认锚点整行唯一。改完**立刻用 `node --check` 验每一段 `<script>`**，
注意一个 HTML 里有多段 script，只验第一段会漏掉主脚本。

### §17 机器的开关和灯在字符画里糊成一片

**原因**：点云光照只看法线。同一个朝向上的「近黑色凹槽」和「白色拨动开关」
会算出**完全相同的亮度**，于是面板细节全糊了。
**做法**：每个点除了法线，再存一份**反照率** `alb = 0.299r + 0.587g + 0.114b`，
亮度 = `alb × (环境光 + 主光 + 边缘光)`。这一步一做，面板立刻能读出结构。

### §18 一开始就上 WebGL，反而走弯路

**原因**：直觉上「3D 就该用 GPU」。早期版本确实用 three.js + `WebGLRenderTarget` +
`readRenderTargetPixels` 跑通了，但那意味着：多一个依赖、多一层坐标系、
而且**没法精确控制每个点落到哪个字符格**（归约逻辑被压在像素缓冲里）。
**做法**：点云渲染根本不需要光栅化三角形 —— 一套自己写的透视投影 + z-buffer
几十行就够，还能顺着每个点的代数下标直接定位到字符格。
**零依赖、单文件、每点可控**，比 GPU 那条路省事得多。

这个项目里最难的不是写代码，是**建立「截图 → 判断 → 改一个参数 → 再截图」的循环**。

所以第 1 轮就把 `#jserr` 和 `?stage&freeze&still` 做出来，
